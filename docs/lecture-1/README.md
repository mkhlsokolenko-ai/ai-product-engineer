# Лекция 1 — Вводная

Материалы вводной лекции курса AI Product Engineer.

- **`Лекция-1-Вводная.pptx`** — презентация (портальный дизайн, 31 слайд), включая
  онбординг на CLI `ape`, лимиты токенов и подключение к моделям курса.

## Скачать (публичные ссылки)
- Презентация: https://s3.engineer-ai.pro/materials/Лекция-1-Вводная.pptx
- Презентация (PDF): https://s3.engineer-ai.pro/materials/lecture1.pdf
- CLI одним файлом: https://s3.engineer-ai.pro/materials/ape.py

## Как пересобрать презентацию
Из корня `Desktop/AIProductEngeenier`:
```bash
py build_slides.py            # -> Лекция_1_Вводная_portal.pptx
```
Шрифты для точного рендера: **Geist** + **JetBrains Mono** (поставить на машину-презентер).

> CLI курса — см. [`../../cli/`](../../cli/) (`ape.py`, README, pyproject).
