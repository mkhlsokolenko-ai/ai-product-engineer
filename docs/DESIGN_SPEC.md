# AI Product Engineer — Design Spec (бриф для дизайнера)

Документ описывает **что и как должно выглядеть и работать** в портале
`engineer-ai.pro`, чтобы дизайнер (или дизайн-агент) собрал «крутой» интерфейс без
догадок. Формат — по образцу `LUDA_DESIGN_AUDIT.md`: коммит значений, user-flow с числом
действий до цели, состояния, scorecard качества. Источник истины по фронту —
`portal/index.html` (SPA, ванильный JS + CSS-переменные, без сборки), бэкенд —
`portal_api/` (FastAPI + Postgres + MinIO).

Связанные документы: [`DESIGN.md`](DESIGN.md) — направление и референс-борд;
этот файл — детальная спека реализации.

---

## 0. Главное требование (заказчик)

> Ожидаемое действие пользователя считывается однозначно: **≤ 2 действий до целевого**.
> Чёткая структура шагов (если А → то Б → затем С), явные кнопки возврата/отмены.

Каждый экран проектируется от **одного целевого действия**. Оно — единственная
`primary`-кнопка на экране. Всё остальное — вторичное (`.btn` без `primary`) или ссылки.
Ниже для каждой вкладки зафиксировано целевое действие и число кликов до него.

## 1. Аудитория, тон, анти-slop

- **Пользователи:** (1) студент курса — вчерашний джун/продакт, учится строить
  AI-продукты; (2) лектор (Соколенко М.В., РУТ МИИТ) — ведёт группу, оценивает, следит
  за рисками; (3) admin.
- **Тон:** дружелюбная обучающая платформа (EdTech), не «дашборд безопасника», не
  «AI-slop». Атрибуты: `warm, spacious, academic, trustworthy`.
- **Дифференциация (чтобы не раствориться в SaaS-супе):**
  1. Инженерный контур в тёплой оболочке — **JetBrains Mono на всех числах** (токены,
     cost, КТ-баллы, RAG-коллекция) поверх мягкой EdTech-палитры.
  2. **Cost/квоты — первоклассная сущность** (лидерборд по токенам, cost-плитки,
     сигналы). Этого нет у Coursera/Skillbox — это ownable-фича курса.
- **Анти-slop-гейт (запрещено):** градиенты ради градиентов; вторая параллельная палитра;
  сырые Tailwind-семафоры `#10B981/#F59E0B`; пурпурно-синие дефолты; стеклянные карточки
  без смысла; иконки-эмодзи в хроме интерфейса (только векторные одноцветные).

## 2. Дизайн-токены (коммит значений)

Единый набор CSS-переменных, две темы (светлая по умолчанию + тёмная по переключателю
и `prefers-color-scheme`). Контраст считан по WCAG 2.1 на фоне карточки.

| Роль | Светлая | Тёмная | Контраст текста |
|---|---|---|---|
| bg-0 (страница) | `#F1EFE8` | `#14171C` | — |
| bg-1 (карточка) | `#FFFFFF` | `#1A1F27` | — |
| bg-2 (вторичный) | `#F7F6F3` | `#232A36` | — |
| bg-inset (поля/трек) | `#F1EFE8` | `#0E1116` | — |
| ink-1 (текст) | `#1A1A1A` | `#E8EAED` | 15:1 / 13:1 ✓ |
| ink-2 (вторичный) | `#5F5E5A` | `#A7B0BC` | 6.5:1 / 7:1 ✓ |
| ink-3 (мета) | `#75736B` | `#8A94A0` | 4.6:1 / 5.3:1 ✓ AA |
| accent | `#534AB7` | `#8B82F0` | 7.3:1 / светлый-на-тёмном ✓ |
| accent-bg (плашка) | `rgba(83,74,183,.09)` | `rgba(139,130,240,.15)` | — |

Никаких literal-hex в компонентах — всё через токены.

### Типографика
- Семейства: **Geist** (UI), **JetBrains Mono** (числа/код/технические строки).
- Шкала (только эти кегли): `12 · 13.5 · 15 · 18 · 22 · 30 px`.
- Веса: **только 400 / 500 / 600 / 700** (загружены). Никаких 560/680/800.
- Роли: h2=22/600, карточный заголовок=18–19/600, body=13.5–14/400, caps-лейбл=10.5/600
  моно uppercase (`.caps`), мета=11–12/400 (`--text-3`).

### Спейсинг (4/8-сетка)
`--s1:4 --s2:8 --s3:12 --s4:16 --s5:24 --s6:32`. Внутренние отступы карточки — 20px
(`--s5`-ish), между карточками — 14px, gap в сетках — 12–14px. **Запрет нечётных
литералов** 9/11/13/15/17/19.

### Радиусы, тени, motion
- Радиусы: `--r-s:8 --r-m:10 --r-l:14`; пилюли — 999px.
- Тень карточки (`--shadow`): светлая `0 1px 2px rgba(0,0,0,.05), 0 4px 16px rgba(0,0,0,.05)`;
  тёмная — глубже. Тени сдержанные, не «парящие».
- Анимация: `transition:.15s` на интерактиве; hover .12–.2s; никаких scroll-параллаксов.
  Кольцо/бары анимируют `width`/`stroke-dashoffset` .3s. Сдержанный минимум.

## 3. Информационная архитектура

**Роли и доступ:**
- `student` — Главная, Курс, Задания, Мой проект, Оценки, Сообщество, Кабинет.
- `lecturer` / `admin` — то же + **Командный центр** (403 для студента и на бэке, и вкладка
  скрыта на фронте).

**Навигация — левый сайдбар (EdTech-паттерн Coursera/Skillbox/Stepik):**
- Десктоп: постоянный левый рельс 216px с иконками; топ-бар 56px несёт бренд +
  переключатель темы + профиль + «Выйти».
- Мобайл (≤720): сайдбар сворачивается в выпадающее меню под топ-баром (кнопка ☰).
- Активный раздел подсвечен `accent-bg` + `accent` текст; иконки — векторные одноцветные
  (см. §8).

Брейкпоинты: `900` (сайдбар 180px, main паддинг 20), `720` (сайдбар → дропдаун, 1 колонка),

широких таблиц лектора.

## 5. Компоненты (спека)

Каждый компонент = токены + все состояния (default/hover/focus-visible/disabled/loading/
empty). Клик-элементы, не являющиеся `<button>/<a>`, получают `role="button" tabindex="0"`
и обработчик Enter/Space.

| Компонент | Спека |
|---|---|
| **Кнопка** `.btn` | высота 40 (sm=32), радиус `--r-m`, gap 8; `.primary`=accent+белый текст; hover=`accent-bg`/`accent-hover`; `:focus-visible`=кольцо accent. **Один primary на экран.** |
| **Карточка** `.card` | `bg-1` + `border-1` + `--shadow`, радиус `--r-l`, паддинг 20, `margin-bottom:14`. |
| **Чип** `.chip` | пилюля 999px, 11/600. Варианты: `done`(ok), `doing`(warn), `todo`(нейтр.), `risk`(crit), `info`(accent). Статусы — только чипами, не текстом-цветом. |
| **Плитка-метрика** `.tile` | лейбл 11.5 `ink-2` + значение 23 моно. Грид `auto-fit minmax(130px,1fr)`. |
| **Таблица** | header `bg-2`, 12/500 `ink-2`; строки — `border-1`, hover `bg-2`. Широкие таблицы лектора — обёртка `overflow-x:auto`. |
| **Inline-edit** `.ie` | прозрачный до hover; hover=рамка `border-1`; focus=`bg-inset`+рамка accent. Автосейв onchange. |
| **Dropzone** `.dropzone` | dashed `border-2`, радиус `--r-l`, центр; hover=accent-border; `.over`(dragover)=accent bg+рамка. Иконка upload (векторная). Клик = открыть выбор файла; drop = загрузка. Мультифайл, прогресс текстом. |
| **Модалка** | backdrop `rgba(0,0,0,.5)`; окно `bg-1`, радиус 14, паддинг 22, max 460. **Заголовок слева, действия справа** (`primary` + `Отмена`). Закрытие по фону и по «Отмена». |
| **Кольцо прогресса** | SVG, r=34, stroke 8, accent на `bg-inset`, % в центре моно 700. `aria-label`. |
| **Bar-chart (лидерборд)** | инлайновый SVG, горизонтальные бары топ-8; свой бар — сплошной accent, чужие — `accent-border`. |
| **Badge/КТ-пилюля** | балл в моно на тонированном фоне (ok/warn/crit по %). |
| **Empty state** | иконка/эмодзи + короткий текст + (если уместно) CTA «что сделать». Никаких пустых `—` без подсказки, где ожидается действие. |
| **Loading** | текст «Загрузка…» (минимум) → желательно skeleton той же сетки. |

## 6. User-flow по вкладкам (цель · шаги · число действий)

Легенда: **ЦД** = целевое действие; **N** = кликов от входа на вкладку до ЦД.

### 6.1 Логин
- ЦД: войти. **N = 1** — `primary` «Продолжить с GitHub». Вторично: «Вход по логину».
- Flow: A(клик GitHub) → редирект Keycloak → назад в портал. Ошибка → снова экран логина.

### 6.2 Главная (home)
- ЦД: **продолжить обучение**. **N = 1** — `primary` «Продолжить обучение →» в герое.
- Структура (сверху вниз):
  1. **Герой**: кольцо прогресса курса + «Привет, %имя%» + «Продолжай: %лекция%» +
     `primary` CTA + вторичная «К заданию · %дедлайн%».
  2. **Текущая лекция / Ближайший дедлайн** (2 карточки; дедлайн красит срочность:
     ≤2 дн — warn-рамка «сегодня/через N дн»).
  3. **Достижения** (иконки, earned/locked).
  4. **С чего начать** — чек-лист онбординга A→B→C→D→E (вошёл → первый MCP → RAG →
     сдача → файл), done/⬜; ссылка «Инструкция по подключению».
  5. **Анонсы**.
- Состояния: до старта курса — бейдж «Курс скоро стартует», кольцо 0%.

### 6.3 Курс (lectures) — карта курса
- ЦД: **открыть материалы текущей лекции**. **N = 1** (текущая неделя авто-раскрыта →
  ссылка «Материалы» видна сразу) / **N = 2** для остальных (раскрыть → ссылка).
- Структура: шапка (пройдено X/15 + кольцо-бар + сводка) → блоки с названиями → карточки
  лекций. Клик по лекции раскрывает: **Чему научишься** (галочки), **Навыки/скиллы**
  (чипы), **Связанное задание** (кнопка «Открыть в Заданиях»), **Материалы**.
- Отметки: пройденные — `done`+приглушены; текущая — accent-рамка «сейчас»; будущие —
  нейтрально. Возврат = свернуть (шеврон) или другой раздел в сайдбаре.
- a11y: заголовок лекции — `role=button tabindex=0 aria-expanded`, Enter/Space.

### 6.4 Задания (homework)
- ЦД: **сдать задание**. **N = 2** — вставить ссылку (A) → `primary` «Сдать» (B).
- Каждая карточка: неделя+название+формат+макс.балл+**чип статуса** (не сдано/сдано/
  доработка/принято) → описание → поле ссылки → поле комментария → кнопка
  «Сдать»/«Обновить сдачу». Если есть оценка — зелёная плашка «Оценка X/макс + фидбэк».
- После сдачи: перерисовка, чип → «сдано» (обратная связь). Валидация: пустая ссылка →
  подсказка.
- Доработка: если статус «на доработку» — фидбэк лектора виден, кнопка «Обновить сдачу».

### 6.5 Мой проект (project)
- ЦД: **сохранить проект** и **загрузить файл**. Save: **N = 1** (`primary` «Сохранить»
  после правки полей); Upload: **N = 1** (drop или клик по зоне).
- Структура: карточка проекта (репозиторий, описание, статус select idea→…→defended,
  `primary` «Сохранить», вторичная «Открыть репозиторий») → плитки (Файлы, RAG-коллекция
  `ape_stu_<логин>`, Cost·неделя, Наблюдаемость) → **Dropzone** загрузки + таблица файлов
  (скачать/удалить). Показывать свободное место в МБ.
- Состояния: файлов нет → «Файлов нет»; лимит 600 МБ → предупреждение при превышении.

### 6.6 Оценки (grades)
- ЦД: read-only — **увидеть баллы**. **N = 0**.
- Структура: достижения → «Итого баллов X / макс» → таблица (неделя, задание, оценка,
  фидбэк). Пусто → «—» с пояснением.

### 6.7 Сообщество (community)
- ЦД: read-only — **увидеть анонсы и своё место**. **N = 0**.
- Структура: анонсы лектора → **лидерборд-график** (SVG топ-8, свой бар акцентный) →
  полная таблица (свой ряд подсвечен + чип «ты»).

### 6.8 Кабинет (cabinet)
- ЦД: **скопировать токен для OpenCode**. **N = 1** — `primary` «Скопировать токен».
- Структура: плитки (токены·неделя, хранилище, прогресс по домашкам) → cost за неделю →
  **Подключение OpenCode**: endpoint `mcp.engineer-ai.pro/mcp`, заголовок Auth, `primary`
  «Скопировать токен», **нумерованные шаги 1→2→3→4** (поставь CLI → пропиши MCP+Auth →
  скопируй скиллы → первый вызов), ссылка на репозиторий.
- Копирование: успех → alert с инструкцией; фолбэк → prompt с токеном.

### 6.9 Командный центр (lecturer/admin)
- Верх: **6 плиток-метрик** (студентов / партнёров / средний балл / в зоне риска /
  cost·неделя / прогресс курса) → **под-вкладки** (Студенты / КТ и оценки / Партнёры /
  Календарь / Сигналы / Материалы / Заметки / Анонсы). Под-вкладки = постоянная строка,
  всегда видно «где я» и как вернуться.
- **Студенты:** таблица, inline-правка партнёра/недели/риска (автосейв), КТ-пилюли
  read-only, cost. Ростер наполняется сам (логины+вызовы MCP); ручное добавление —
  модалка (**N=2**: «+ Добавить» → заполнить → «Добавить»).
- **КТ и оценки:** статистика по 6 КТ (средний/прошли/на доработку/кому помочь) +
  проверка сдач. Оценивание: **N=2** — балл/статус/фидбэк → «Сохранить».
- **Партнёры:** карточки (компания/контакт/студенты). Добавить: **N=2** (модалка).
  Удалить: **N=2** (× → подтверждение).
- **Календарь:** события курса (даты считаются от старта). Добавить: **N=2** (модалка).
- **Сигналы:** авто-риски (ручной риск / >80% квоты / КТ<60% / отставание) — read-only
  список, ведёт лектора к действию.
- **Материалы:** **Dropzone** (drag-drop, **N=1**) → список файлов → «привязать к неделе N»
  (**N=2**: выбрать неделю → «привязать»), удалить.
- **Заметки:** автосейв textarea. **Анонсы:** форма (заголовок+текст → «Опубликовать»,
  **N=2**) + список опубликованных.
- Все модалки: заголовок слева, «Добавить»(primary)+«Отмена»(возврат).

## 7. Сквозные сценарии (end-to-end)

1. **Онбординг студента (первый вход):** GitHub-логин → Главная (кольцо 0%, чек-лист
   «С чего начать») → Кабинет → «Скопировать токен» → подключил OpenCode → первый вызов →
   чек-лист заполняется. Цель — довести до первого MCP-вызова за минимум кликов.
2. **Сдача ДЗ:** Главная «К заданию» → Задания → ссылка + «Сдать» → чип «сдано». Позже
   Оценки/Задания показывают балл и фидбэк; при «доработке» — «Обновить сдачу».
3. **Работа над проектом:** Мой проект → заполнить репо/статус → «Сохранить»; drag-drop
   артефактов; RAG-индексация через MCP.
4. **Оценивание (лектор):** Командный центр → КТ и оценки → проверка сдач → балл+статус+
   фидбэк → «Сохранить». Сигналы подсвечивают отстающих.
5. **Планирование (лектор):** Партнёры (добавить компанию) → Студенты (привязать партнёра,
   отметить риск) → Календарь (событие) → Материалы (загрузить PDF, привязать к неделе) →
   Анонсы (опубликовать перенос).

## 8. Иконосистема

Векторные **одноцветные** иконки (lucide-стиль): `viewBox 0 0 24 24`, `fill:none`,
`stroke:currentColor`, `stroke-width:1.8`, `linecap/linejoin:round`. Цвет наследуется от
текста (в сайдбаре — accent на активном). Набор: home, lectures(graduation-cap),
homework(clipboard-check), project(rocket), grades(bar-chart), community(users),
cabinet(gear), admin(layout-dashboard), sun/moon(тема), menu(☰), upload(dropzone),
copy(токен). **Эмодзи допустимы только как контент** (достижения-геймификация), не в хроме.

## 9. Accessibility (обязательно)

- Контраст: текст ≥ 4.5:1, крупный/иконки ≥ 3:1 (см. токены — проверено).
- `:focus-visible` кольцо на всём интерактиве (глобально).
- Иконочные кнопки — `aria-label`; кольцо/график — `role=img aria-label`.
- Клик-`div` (карточка лекции) — `role=button tabindex=0` + Enter/Space + `aria-expanded`.
- Клавиатурный порядок логичен; формы: `label` связаны, ошибки текстом рядом.
- Размер целей ≥ 32×32.

## 10. Scorecard качества (цель — держать ≥ 8/10 по каждому)

| # | Измерение | Критерий приёмки |
|---|---|---|
| 1 | Консистентность цвета | одна палитра, всё через токены, 0 сырых Tailwind-семафоров |
| 2 | Типо-иерархия | ≤ 6 кеглей, веса только 400/500/600/700 |
| 3 | Ритм отступов | 4/8-сетка, 0 нечётных литералов в новых компонентах |
| 4 | Консистентность компонентов | один `.btn`+модификаторы, токен-радиусы |
| 5 | Адаптивность | нет гориз. скролла (кроме явных таблиц); сайдбар→дропдаун |
| 6 | Тёмная тема | 0 жёстко-светлых панелей, всё из токенов |
| 7 | Анимация | сдержанная, ≤ .3s, без скролл-джанка |
| 8 | Доступность/контраст | WCAG AA пройден, focus-visible, клавиатура |
| 9 | Плотность | структурировано (карточки/плитки/таблицы), читаемо на мобиле |
| 10 | Полировка | все состояния: hover/focus/disabled/loading/empty/success |

## 11. Что реализовано vs доработать

**Готово:** светлая+тёмная тема с токенами; левый сайдбар с векторными иконками; герой
«Продолжить» + кольцо; карта курса с раскрытием; drag-drop загрузки (студент+лектор);
командный центр (студенты/КТ/партнёры/календарь/сигналы/материалы/заметки/анонсы);
лидерборд-график; чипы-статусы; focus-visible + базовая клавиатурная доступность;
контраст мета-текста под AA.

**Доработать (backlog для дизайна):**
- Полный token-свип по старым инлайновым отступам (часть ещё «на глаз»).
- Skeleton-загрузка вместо «Загрузка…» в async-блоках.
- Группировка разделов в сайдбаре (ОБУЧЕНИЕ / ПРОЕКТ / ЛЕКТОР) с caps-заголовками.
- Пустые состояния с явным CTA везде, где ожидается действие.
- Микро-состояние success (toast) на сдаче/сохранении вместо тихой перерисовки.
- Планируется: Telegram-бот (уведомления о переносах, сдача ДЗ, подтверждение участия,
  опросы) — отдельный флоу, «в конце».

## 12. Технические границы (чтобы дизайн был реализуем)

- SPA без сборки: один `index.html`, ванильный JS, CSS-переменные. Компоненты — строки-
  шаблоны; никаких React/Tailwind. Значит: дизайн отдаёт **токены + CSS-классы**, не JSX.
- Иконки — инлайновый SVG (реестр `ICONS`), не спрайт-файлы.
- Графики — инлайновый SVG (без внешних библиотек), тема-aware через `currentColor`/токены.
- Данные живые: прогресс/оценки/cost/ростер — из Postgres; материалы — публичный бакет
  MinIO `s3.engineer-ai.pro/materials/*`.
