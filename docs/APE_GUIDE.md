# APE — курсовой CLI-агент. Полная инструкция

**APE** — это твой персональный ИИ-инженер в терминале: интерактивный агент курса
AI Product Engineer. Пишет код, ведёт ресёрч, читает твои файлы, запускает команды агентов
параллельно, помнит контекст между запусками. Всё — через курсовой шлюз (единая квота,
без личных ключей к моделям).

Версия: **1.16.0**

---

## 1. Установка и обновление

Нужен Python 3.9+.

```bash
pip install -U "git+https://github.com/mkhlsokolenko-ai/ai-product-engineer#subdirectory=cli"
```

Эта же команда и ставит, и обновляет (флаг `-U`). Обновляйся, когда выходят новые фичи —
версия видна в баннере при запуске.

**Запуск:**

```bash
ape          # если Scripts в PATH
python -m ape   # если ape не находится (частый случай на Windows)
```

Открывается интерактивная сессия (REPL) — как Claude Code, только наш.

---

## 2. Вход — `/login` (прямо в сессии!)

С версии 1.16.0 логиниться можно **не выходя из сессии**:

```
/login
```

Откроется браузер → вход через GitHub → готово, можно продолжать. **Перезапускать APE
не нужно.** Если сессия истекла посреди работы — просто набери `/login` ещё раз.

- `/logout` — выйти из аккаунта.
- `/whoami` — кто ты сейчас.

---

## 3. Как разговаривать с APE

Просто пиши запрос — по умолчанию идёт в режим кода (Qwen3.8-27B):

```
напиши функцию на python, которая считает recall@k
```

Явно выбрать движок под задачу:

```
/code  <запрос>     → код на Qwen3.8-27B (быстрый кодер)
/ask   <запрос>     → ресёрч и рассуждения на DeepSeek (длинные ответы, до 32k токенов)
```

Сменить режим по умолчанию: `/mode code` или `/mode ask`.

**Управление выводом:**
- Длинные ответы сворачиваются (превью 30 строк) — раскрыть полностью: `/more`.
- Код никогда не сворачивается; в диффах удалённое красное, добавленное — голубое.
- Прервать зациклившийся/долгий ответ — **Esc** или **Ctrl+C** (сессия не падает).

## 4. Работа с файлами — `@путь`

APE **сам не сканирует** твои папки. Ты явно даёшь ему файл через `@` с полным путём:

```
@C:\Users\Иван\project\main.py объясни, что тут не так
@/home/ivan/notes/research.md сделай саммари на 5 пунктов
```

Работают пути **с пробелами** (например `C:\Users\Иван Петров\...`). Нажми **Tab** для
автодополнения пути.

---

## 5. Сохранение результата — `/save`

```
/save research.md          → сохранить последний ответ на свой компьютер
/save cloud research.md     → сохранить сразу в облачную папку своего проекта (через портал)
```

Облачные файлы потом видны в портале, во вкладке «Проект».

## 6. Скиллы — `/skills`

Стартовый набор скиллов курса (icp-interviewer, mlsdd-writer, adr-writer, rag-architect,
grill-me и др.) можно включать/выключать:

```
/skills            → меню: список, вкл/выкл по Y/N
```

Активные скиллы подмешиваются в системный промпт — при ответах видно 🧩, какие применяются.

---

## 7. Своя база знаний — `/rag`

```
/rag index @путь/к/файлу     → проиндексировать документ в свою RAG-коллекцию
/rag search <запрос>          → семантический поиск по своим документам
```

Под капотом — BGE-M3 embeddings + reranker + Qdrant, всё в твоей персональной коллекции.

---

## 8. Мульти-агенты — `/agents` и доска `/board`

Главная суперсила APE. Планировщик разбивает задачу и запускает **несколько агентов
параллельно** (оркестрация волнами: fan-out → барьер → fan-in), с tool-calling.

```
/agents найди в @research.md ключевые риски, раздай подзадачи и собери сводку
```

Агенты общаются через **Blackboard** — общую доску (event-sourced): факты, заметки, claim'ы,
чтобы не дублировать работу и переиспользовать находки друг друга.

```
/board              → показать доску текущей задачи
/board post <текст>  → вручную добавить заметку на доску
/board compact       → свернуть длинный лог в снапшот
/board clear         → очистить доску
```

Инструменты агентов: RAG-поиск, чтение/запись файлов, вопрос модели, работа с доской и
машиночитаемый слой данных (`data_query`, см. ниже).

## 9. Слой данных — `/data` (Data Plane)

Агентам данные нужны как машине, а не как человеку. `/data` даёт **рецепты данных**:
декларативно (JSON) описываешь, как превратить сырой источник в чистый типизированный JSON.

```
/data new sales             → создать шаблон рецепта ~/.ape/recipes/sales.json
/data run sales             → применить: источник → canonical JSONL (с provenance/схемой/ttl)
/data query transaction      → прочитать чистые данные (можно с фильтром: date=2026-08-02)
/data recipes                → список рецептов
```

Рецепт (пишет человек): `source (csv|json) → map+cast → rules (assert / pii_mask) → emit`.
Касты: `money` (чистит ₽/пробелы/запятые), `int`, `lower`. Правила: `{"assert":"amount > 0"}`,
`{"pii_mask":["email"]}`. Дальше агент берёт данные тулом `data_query` в своём цикле.

---

## 10. Память между сессиями — `/memory`

APE помнит ход работы и дистиллирует длинный контекст в структурный конспект (цель, решения,
факты, артефакты, открытые вопросы) — чтобы можно было вернуться к обсуждению.

```
/memory     → показать конспект памяти
/distill     → сжать память в конспект прямо сейчас
/forget      → очистить память текущей сессии
```

---

## 11. Квота и расход — `/usage`

```
/usage      → сколько токенов израсходовано и сколько осталось
```

Лимит — **25 млн токенов в неделю** на студента (сброс в понедельник). Отдельных лимитов на
сессии нет — переподключайся сколько нужно. Остаток всегда виден в шапке сессии.

---

## 12. Шпаргалка по командам

| Команда | Что делает |
|---|---|
| `/login` · `/logout` · `/whoami` | вход в сессии / выход / кто я |
| `/code` · `/ask` · `/mode` | код (Qwen) / ресёрч (DeepSeek) / режим по умолчанию |
| `@путь` | подхватить файл (Tab — автодополнение) |
| `/save` · `/save cloud` | сохранить ответ на комп / в проект |
| `/skills` | вкл/выкл скиллы |
| `/rag index` · `/rag search` | своя база знаний |
| `/agents` · `/board` | мульти-агенты волнами / общая доска |
| `/data` | рецепты данных (Data Plane) |
| `/memory` · `/distill` · `/forget` | память сессии |
| `/usage` | расход и остаток квоты |
| `/more` | раскрыть последний ответ |
| `/help` | справка · `/clear` — очистить экран · `/exit` — выход |

Набери `/` в строке — выпадет список всех команд. **Esc** прерывает текущую операцию.
